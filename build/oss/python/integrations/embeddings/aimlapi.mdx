This will help you get started with AI/ML API embedding models using LangChain.

## Overview

[AI/ML API](https://aimlapi.com/) is a unified, OpenAI-compatible API giving access to embedding models — such as `openai/text-embedding-3-small`, `openai/text-embedding-3-large`, and models from Alibaba and Google — through a single endpoint and API key.

## Setup

To access AI/ML API embedding models you'll need to create an [AI/ML API account](https://aimlapi.com/), get an API key, and install the `langchain-aimlapi` integration package.

### Credentials

Head to the [AI/ML API dashboard](https://aimlapi.com/app/keys) to sign up and generate an API key. Once you've done this set the `AIMLAPI_API_KEY` environment variable:

```python
import getpass
import os

if not os.getenv("AIMLAPI_API_KEY"):
    os.environ["AIMLAPI_API_KEY"] = getpass.getpass("Enter your AI/ML API key: ")
```

To enable automated tracing of your model calls, set your [LangSmith](/langsmith/observability) API key:

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### Installation

The LangChain AI/ML API integration lives in the `langchain-aimlapi` package:

```bash
pip install -qU langchain-aimlapi
```

## Instantiation

```python
from langchain_aimlapi import AimlapiEmbeddings

embeddings = AimlapiEmbeddings(
    model="text-embedding-3-small",
)
```

## Indexing and retrieval

Embedding models are often used in retrieval-augmented generation (RAG) flows, both as part of indexing data as well as later retrieving it. For more detailed instructions, see the [RAG tutorials](/oss/python/deepagents/rag).

```python
from langchain_core.vectorstores import InMemoryVectorStore

text = "LangChain is the framework for building context-aware reasoning applications"

vectorstore = InMemoryVectorStore.from_texts(
    [text],
    embedding=embeddings,
)

retriever = vectorstore.as_retriever()
retrieved_documents = retriever.invoke("What is LangChain?")
retrieved_documents[0].page_content
```

```text
'LangChain is the framework for building context-aware reasoning applications'
```

## Direct usage

Under the hood, the vectorstore and retriever implementations call `embeddings.embed_documents(...)` and `embeddings.embed_query(...)`. You can call these directly for your own use cases.

### Embed single texts

```python
single_vector = embeddings.embed_query(text)
print(str(single_vector)[:100])
```

### Embed multiple texts

```python
two_vectors = embeddings.embed_documents([text, "LangGraph is a library for building stateful, multi-actor applications with LLMs"])
for vector in two_vectors:
    print(str(vector)[:100])
```
