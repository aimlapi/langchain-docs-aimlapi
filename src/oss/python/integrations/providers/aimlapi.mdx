This page covers all LangChain integrations with [AI/ML API](https://aimlapi.com/).

[AI/ML API](https://aimlapi.com/) is a unified, OpenAI-compatible API giving access to 1,000+ AI models — LLMs, image, video, audio, and embedding models — from providers such as OpenAI, Anthropic, Google, and Meta, through a single endpoint and API key.

## Installation

```bash
pip install -U langchain-aimlapi
```

## Environment

Get an API key from the [AI/ML API dashboard](https://aimlapi.com/app/keys) and set it as the `AIMLAPI_API_KEY` environment variable.
