This guide provides a quick overview for getting started with AI/ML API [chat models](/oss/langchain/models). For detailed documentation of all `ChatAimlapi` features and configurations head to the [API reference](https://reference.langchain.com/python/langchain-aimlapi/chat_models/ChatAimlapi).

[AI/ML API](https://aimlapi.com/) is a unified, OpenAI-compatible API giving access to 1,000+ models — including chat, image, video, audio, and embedding models — from providers such as OpenAI, Anthropic, Google, and Meta, through a single endpoint and API key. `ChatAimlapi` is a drop-in replacement for `langchain_openai.ChatOpenAI` pointed at AI/ML API's endpoint, so any model id AI/ML API serves can be used directly.

## Setup

```bash
pip install -qU langchain-aimlapi
```

### Credentials

Get an API key from the [AI/ML API dashboard](https://aimlapi.com/app/keys) and set it as the `AIMLAPI_API_KEY` environment variable:

```python
import getpass
import os

if not os.getenv("AIMLAPI_API_KEY"):
    os.environ["AIMLAPI_API_KEY"] = getpass.getpass("Enter your AI/ML API key: ")
```

To enable automated tracing of your model calls, set your [LangSmith](/langsmith/observability) API key:

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## Instantiation

Now we can instantiate our model object and generate chat completions. AI/ML API model ids are namespaced by the underlying provider (e.g. `openai/gpt-4o`):

```python
from langchain_aimlapi import ChatAimlapi

llm = ChatAimlapi(
    model="openai/gpt-4o",
    temperature=0,
    # other params...
)
```

## Invocation

```python
messages = [
    (
        "system",
        "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ),
    ("human", "I love programming."),
]
ai_msg = llm.invoke(messages)
ai_msg
```

```text
AIMessage(content="J'adore la programmation.", response_metadata={'finish_reason': 'stop'}, id='run-...')
```

## Streaming

```python
for chunk in llm.stream("Write a short poem about the sea."):
    print(chunk.content, end="", flush=True)
```

## Async

```python
await llm.ainvoke(messages)
```

## Tool calling

`ChatAimlapi` supports the standard LangChain tool-calling interface for models routed to a provider that supports it:

```python
from pydantic import BaseModel, Field


class GetWeather(BaseModel):
    """Get the current weather in a given location"""

    location: str = Field(description="The city and state, e.g. San Francisco, CA")


llm_with_tools = llm.bind_tools([GetWeather])
ai_msg = llm_with_tools.invoke("What is the weather like in San Francisco?")
ai_msg.tool_calls
```

```text
[{'name': 'GetWeather',
  'args': {'location': 'San Francisco, CA'},
  'id': 'call_...',
  'type': 'tool_call'}]
```

## Structured output

```python
class Movie(BaseModel):
    """A movie with details."""

    title: str = Field(description="The title of the movie")
    year: int = Field(description="The year the movie was released")


structured_llm = llm.with_structured_output(Movie)
structured_llm.invoke("Provide details about the movie Inception")
```

```text
Movie(title='Inception', year=2010)
```
